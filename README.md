 convermani
ConvertMoney is a premium currency converter that supports 3 languages and 3 design themes.
💎 КонверМани | ConverterMoney | 转换金钱

> Стильный минималистичный конвертер валют с поддержкой мультиязычности и тем оформления

## ✨ Особенности

- 🎨 3 темы оформления — Тёмная, Светлая, Midnight
- 🌍 3 языка — Русский, English, 中文
- 🪟 Стеклянный морфизм — дизайн в стиле Apple с эффектом размытия
- 💱 7 валют — RUB, USD, EUR, GBP, CNY, JPY, CHF
- 🔄 Автообновление курсов — каждые 10 минут
- 📱 Адаптивный дизай* — идеально на всех устройствах
- ⚡ Быстрая конвертация — мгновенный расчёт
- 💾 Сохранение настроек — язык и тема сохраняются

 🚀 Демо

Просто открой `index.html` в браузере — всё работает из коробки!

 🛠 Технологии

- HTML5, CSS3, JavaScript (Vanilla)
- ExchangeRate API v6
- CSS Custom Properties для тем
- LocalStorage для сохранения настроек
